**Sistema de Gerenciamento de Estoque com Java, JDBC e MySQL**

Aplicação desenvolvida em Java com integração ao MySQL, utilizando JDBC para persistência dos dados e o padrão DAO para organização do acesso ao banco de dados.

O projeto foi desenvolvido com o objetivo de praticar conceitos de Programação Orientada a Objetos, integração com banco de dados e operações CRUD.

**🚀 Tecnologias utilizadas**

Java 17

MySQL

JDBC

Git/GitHub

Eclipse

**⚙️ Funcionalidades**

Cadastro de produtos

Listagem de produtos

Busca de produto por ID

Atualização de produtos

Exclusão de produtos

Entrada de estoque

Saída de estoque

Validação de dados

Tratamento de exceções


**📗 Conceitos praticados**

Encapsulamento

Classes e métodos

Collections

Padrão DAO

PreparedStatement

Tratamento de exceções

Regras de negócio

Integração entre aplicação Java e banco de dados MySQL

**🧱 Estrutura do projeto**

O projeto utiliza o padrão DAO para separar a lógica de acesso ao banco de dados das demais partes da aplicação.

**🎲 Banco de dados**

O sistema utiliza o MySQL para armazenar os produtos cadastrados.

A conexão com o banco é realizada através do JDBC, permitindo que a aplicação Java execute operações de consulta, inserção, atualização e exclusão de dados
